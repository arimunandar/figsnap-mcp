Start it in a terminal with npm run daemon. It prints the token on the line marked token — or read it back any time with cat ~/.figsnap-mcp/agent-token. Paste it below.

Pairing is a one-time job: the token is kept in this Figma account's own storage, so the panel reconnects itself from then on. If it ever leaks, restart the daemon with --new-token and paste the new one.

Pairing

Reaching it from a terminal

The daemon is the only thing that talks to Figma. An MCP client reaches it through agent/mcp-stdio.mjs and needs no token of its own — it reads the same ~/.figsnap-mcp/agent-token this panel was paired with. Nothing to paste, nothing to configure. 

claude mcp add figsnap-mcp -s user -- node <repo>/agent/mcp-stdio.mjs

Nothing here leaves this machine: the socket is loopback only, there is no account, and the saved set below lives in Figma's own per-user storage.

Reading is always allowed. Writing is not, until you say so.
